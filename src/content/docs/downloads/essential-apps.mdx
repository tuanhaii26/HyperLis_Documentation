## 2. Tổng quan

Mục **Essential Apps** tập hợp danh sách các phần mềm phổ biến nhất tại Việt Nam và trên thế giới, được phân loại rõ ràng giúp kỹ thuật viên cài đặt máy cho khách hàng nhanh chóng mà không cần tải từng bộ cài từ trình duyệt.

## 3. Bảng phân loại phần mềm

| Nhóm phần mềm | Ứng dụng tích hợp |
| :--- | :--- |
| **Bộ gõ Tiếng Việt** | EVKey, UniKey |
| **Nén & Giải nén** | 7-Zip (64-bit), WinRAR |
| **Trình duyệt Web** | Google Chrome, Mozilla Firefox, Brave, Microsoft Edge |
| **Hỗ trợ từ xa** | UltraViewer, AnyDesk, TeamViewer |
| **Đa phương tiện & Đọc PDF** | VLC Media Player, Foxit PDF Reader, K-Lite Codec Pack |
| **Chẩn đoán phần cứng** | CPU-Z, GPU-Z, CrystalDiskInfo, HWMonitor |

## 4. Hướng dẫn cài đặt hàng loạt

<Steps>
1. Mở HyperLis, chọn tab **Tải xuống > Essential Apps**.
2. Đánh dấu tích vào các phần mềm bạn muốn cài đặt trên máy tính.
3. Nhấn **Batch Install**.
4. Chờ thanh tiến trình hoàn tất 100%. Toàn bộ biểu tượng sẽ xuất hiện sẵn sàng trên màn hình Desktop.
</Steps>
