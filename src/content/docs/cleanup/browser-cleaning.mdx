## 2. Tổng quan

**Browser Cleaning** giúp bạn dọn dẹp tập trung bộ nhớ đệm (Cache), cookie rác, tệp tin tải về tạm thời và nhật ký duyệt web trên toàn bộ các trình duyệt đã cài đặt (Google Chrome, Microsoft Edge, Mozilla Firefox, Brave Browser, Opera).

## 3. Hướng dẫn thực hiện từng bước

<Steps>
1. Đóng toàn bộ các cửa sổ trình duyệt đang mở.
2. Mở HyperLis, chọn tab **Dọn dẹp > Browser Cleaning**.
3. Tích chọn các trình duyệt cần làm sạch và các loại dữ liệu (Cache, Cookies, History).
4. Nhấn **Clean Browsers**.
</Steps>

<Aside type="caution">
Nếu bạn chọn xóa **Cookies**, bạn sẽ cần phải đăng nhập lại tài khoản trên các website đang dùng.
</Aside>
