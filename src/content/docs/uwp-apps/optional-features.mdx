## 2. Tổng quan

Mục **Optional Features** cho phép bạn bật/tắt nhanh các tính năng nâng cao của Windows mà không cần mở giao diện `optionalfeatures.exe` truyền thống: *Windows Subsystem for Linux (WSL)*, *Windows Sandbox*, *Virtual Machine Platform*, *Hyper-V*, *SMB 1.0 (Legacy)*, *DirectPlay*.

## 3. Hướng dẫn thực hiện

<Steps>
1. Mở HyperLis, chọn tab **Ứng dụng UWP > Optional Features**.
2. Gạt công tắc sang **Enable** hoặc **Disable** tương ứng với từng tính năng.
3. Nhấn **Apply Changes**.
4. Khởi động lại Windows để hoàn tất cài đặt/gỡ bỏ tính năng.
</Steps>

<Aside type="caution">
Nếu bạn chơi game online có Anti-cheat kernel (như Valorant Vanguard / FACEIT) hoặc dùng giả lập (Nox, LDPlayer), hãy kiểm tra yêu cầu về Hyper-V và Virtual Machine Platform trước khi tắt.
</Aside>
