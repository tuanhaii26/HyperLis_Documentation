## 2. Tổng quan

Tính năng **Disk Cleanup** trong HyperLis tự động thực thi dọn dẹp hệ thống ở cấp độ nâng cao (tương đương lệnh `cleanmgr.exe /sageset` và `DISM /Cleanup-Image /StartComponentCleanup /ResetBase`), giúp lấy lại hàng chục GB dung lượng ổ `C:`.

## 3. Hướng dẫn thực hiện từng bước

<Steps>
1. Mở HyperLis, chọn tab **Dọn dẹp > Disk Cleanup**.
2. Chọn các phân vùng cần làm sạch:
   * **Previous Windows Installations (Thư mục Windows.old)**
   * **Windows Update Component Store (WinSxS Cleanup)**
   * **System Error Memory Dump Files**
3. Nhấn nút **Run System Disk Cleanup**.
4. Chờ quá trình dọn dẹp hoàn tất (có thể mất 3 - 10 phút tùy dung lượng cần nén).
</Steps>

<Aside type="caution">
Sau khi xóa thư mục `Windows.old` và dọn dẹp WinSxS, bạn sẽ không thể hạ cấp (Rollback) về phiên bản Windows Build trước đó.
</Aside>
